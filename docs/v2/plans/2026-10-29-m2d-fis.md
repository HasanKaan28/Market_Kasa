# Market Kasa v2 · M2d Fiş — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Her satışın fişi ekranda görülür, istenirse yazdırılır (tarayıcının penceresinden yazıcıya ya da "PDF olarak kaydet") ve müşteriye WhatsApp ile metin olarak gönderilir; yazdırma ayarlardan açılır ve satıştan sonra kendiliğinden basılabilir.

**Architecture:** Fiş içeriği bir kez, saf bir modelde (`buildReceipt`) hesaplanır; ekran görünümü, yazdırma görünümü (58/80 mm, `@media print`) ve WhatsApp metni (32/48 sütun) aynı modelden çizilir, böylece üçü hiçbir zaman ayrışmaz. Fiş ayarları cihaza özeldir (`localStorage`). Yazdırma, sayfanın geri kalanını gizleyen bir yazdırma kökü ve `window.print()` ile yapılır; Electron'da pencere açmadan basma ve Android paylaşımı M8'de.

**Tech Stack:** React 19, CSS `@media print` ve `@page`, M2a–M2c kasa bileşenleri.

**Spec:** [docs/v2/DESIGN.md](../DESIGN.md): §12 Fiş ve yazdırma (ayarlar: kapalı/açık, otomatik, 58/80 mm, başlık, alt bilgi; "Bilgi fişidir, mali değeri yoktur."; web'de tarayıcının yazdırma penceresi), §10 Kasa satırı (fiş PDF ve WhatsApp, iptal edilmiş fiş işaretli). Kullanıcı kararı: yazdırma isteğe bağlı, ayarlardan; donanım şimdilik yok.

## Review Focus

1. **Ekran, yazdırma ve metin aynı rakamları göstermeli:** indirimli, bölünmüş, veresiyeli ve iadesi olan bir satışta üç çıktı aynı toplamları vermeli. → Task 1, Task 2
2. **Yazdırma sırasında sayfanın geri kalanı basılmamalı;** fiş yazdırıldıktan sonra kasa ekranı bozulmamalı. → Task 4
3. **Otomatik yazdırma:** yalnız ayarda açıksa ve yalnız yeni satışta; iptal ya da iade sonrası değil. → Task 5
4. **WhatsApp bağlantısı:** müşterinin telefonu varsa doğru biçimde (0532… → 90532…), yoksa numarasız; metin URL'de doğru kodlanmalı. → Task 2
5. **Uzun ürün adları ve büyük tutarlar** 32 sütuna sığmalı (ad kırpılır, tutar hiç kırpılmaz). → Task 2

### Task 1: Fiş modeli

**Files:**
- **Create:** `src/pos/receipt.ts`
- **Test:** `src/pos/receipt.test.ts`

**Interfaces:**
- **Consumes:** `SaleRecord`, `SaleStatus` (M2b), `formatTRY`, `PAYMENT_LABELS`, `formatQty`, `formatDateTime`.
- **Produces:** `type ReceiptModel = { header: string[]; receiptNo: string; dateTime: string; lines: { name: string; detail: string; discount?: string; amount: string }[]; totals: { label: string; amount: string }[]; vat: { label: string; amount: string }[]; payments: { label: string; amount: string }[]; customer?: string; marks: string[]; footer: string[] }` ve `buildReceipt(sale: SaleRecord, context: { marketName: string; deviceName: string; header?: string; footer?: string; customerName?: string; status?: { voided: boolean; returnedAny: boolean } }): ReceiptModel`.
  - Satır: ad; "{adet} × {birim fiyat}"; satır indirimi varsa "İndirim −{tutar}"; tutar = brüt − satır indirimi.
  - Toplamlar: "Ara toplam" (satır tutarlarının toplamı), sepet indirimi varsa "Sepet indirimi −{tutar}", "Toplam".
  - KDV: oran başına "KDV %1 (dahil)" ve tutar (`vatByRate`).
  - Ödemeler: yöntem başına; nakitte `cashGiven` varsa "Alınan" ve "Para üstü".
  - İşaretler: iptal → "İPTAL EDİLDİ"; iade var → "İADESİ VAR".
  - Alt bilgi: ayardaki alt bilgi (varsa) ve her zaman "Bilgi fişidir, mali değeri yoktur.".

- [ ] **Step 1: Başarısız testleri yaz:** `it('lists lines and totals that add up')` (2 Ekmek + Süt, Süt'te ₺2,50 satır indirimi, ₺5 sepet indirimi, nakit ₺100 → satır tutarları ₺30,00 ve ₺40,00, ara toplam ₺70,00, sepet indirimi −₺5,00, toplam ₺65,00, alınan ₺100,00, para üstü ₺35,00), `it('marks voided and returned receipts')`, `it('shows the market header, the customer and the fixed footer')`, `it('lists every payment of a split sale')`.
- [ ] **Step 2–4:** Run: `npm test -- src/pos/receipt && npm run lint && npm run typecheck` · önce FAIL, sonra PASS.
- [ ] **Step 5: Commit** — `git commit -m "feat(pos): build a receipt model from a sale"`

### Task 4: Fiş görünümü ve yazdırma

**Files:**
- **Create:** `src/pos/ReceiptView.tsx`, `src/pos/printReceipt.tsx`
- **Modify:** `src/app/app.css` (yazdırma kuralları)
- **Test:** `src/pos/ReceiptView.test.tsx`, `src/pos/printReceipt.test.tsx`

**Interfaces:**
- **Produces:**
  - `ReceiptView({ model, paperWidth }: { model: ReceiptModel; paperWidth: 58 | 80 })`: modeli fiş düzeninde çizer (`aria-label` "Fiş {no}"); genişlik `paperWidth` mm.
  - `printReceipt(model: ReceiptModel, paperWidth: 58 | 80, print?: () => void): void`: `#print-root` kökünü (yoksa oluşturur) fişle doldurur, `@page` genişliğini ayarlar, `print()` (varsayılan `window.print`) çağırır, `afterprint` olayında kökü temizler.
  - `app.css`: `@media print { body > :not(#print-root) { display: none } #print-root { display: block } }`; ekranda `#print-root { display: none }`.

- [ ] **Step 1: Başarısız testleri yaz:** `it('shows the receipt lines and footer')` (ReceiptView), `it('fills the print root and calls print')` (sahte `print` çağrılır; kökte fiş no ve "Bilgi fişidir" var), `it('clears the print root after printing')` (`afterprint` olayı sonrası kök boş).
- [ ] **Step 2–4:** Run: `npm test -- src/pos/ReceiptView src/pos/printReceipt && npm run lint && npm run typecheck`.
- [ ] **Step 5: Commit** — `git commit -m "feat(pos): show and print a receipt"`
